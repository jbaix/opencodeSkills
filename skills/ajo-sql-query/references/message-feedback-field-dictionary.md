# Diccionario exhaustivo: AJO Message Feedback Event Schema

Fuente: Experience League, *AJO schema dictionary* (`https://experienceleague.adobe.com/tools/ajo-schemas/schema-dictionary.html?lang=en`), exportado a `ajo schema dictionary.md` (235 campos, esquema **AJO Message Feedback Event Schema**).

Notas de uso:

- Las rutas están en **dot notation** y listas para usar en SQL. Los nombres son *case-sensitive*.
- `array` / `object` indican que el campo es un array o un struct: usa `EXPLODE(...)` para arrays y `.` para structs, y `[0]` para acceder al primer elemento.
- Los campos de `_experience.decisioning.*`, `messageProfile.*`, `emailChannelContext.*`, `smsChannelContext.*`, `pushChannelContext.*` y `whatsAppChannelContext.*` también aparecen en los datasets de tracking (`ajo_email_tracking_experience_event_dataset`, `ajo_push_tracking_experience_event_dataset`).
- `feedbackStatus`, `messageFailure.type`, `messageFailure.category`, `messageType`, `channelType` y `eventType` son los enums más usados. Los valores posibles están en la última columna.
- El dataset `ajo_message_feedback_event_dataset` registra **intentos de entrega**; no contiene aperturas ni clics (para eso usa los datasets de tracking).
- El diccionario refleja el esquema **publicado** por Adobe; el sandbox puede no tener todos los campos. En particular, `messageExecution.journeyVersionNodeID` falta en algunos entornos. Antes de usar un campo poco común, valida con `information_schema.columns` (patrón 1b) y, si no existe, usa una alternativa documentada en `fields.md`.
