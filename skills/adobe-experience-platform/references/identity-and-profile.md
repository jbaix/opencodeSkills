# Identity & Real-time Customer Profile

All endpoints below are **GET**. Send on every request:
`Authorization: Bearer <ACCESS_TOKEN>`, `x-api-key: <API_KEY>`, `x-gw-ims-org-id: <ORG_ID>`,
`x-sandbox-name: <SANDBOX>` (Platform services only), plus the endpoint `Accept` header.

- **Docs:** https://developer.adobe.com/experience-platform-apis/references/identity-service

### `GET /data/core/identity/identity` — Retrieve an identity

You can retrieve an identity (in the form of an XID string) by performing a GET request, given the identity namespace and an ID in that identity namespace.

**Query parameters:**
- `namespace` — namespace code. One of `namespace` or `nsid` is required.
- `nsid` — namespace id. One of `namespace` or `nsid` is required. `nsid` will only be used if `namespace` was not provided.
- `id` **(required)** — Id in given namespace

**`Accept`:** `application/vnd.adobe.identity+json;version=1.2`

**Query parameters:**
- `xid` — Identity string as returned by /identity GET api
- `nsid` — namespace id
- `namespace` — namespace code
- `id` — Id in given namespace
- `graph-type` — Graph type (output type) you want to get the cluster from

**`Accept`:** `application/vnd.adobe.identity+json;version=1.2`

### `GET /data/core/idnamespace/identities` — Lists all identity namespaces available for the IMS Organization

The `https://platform.adobe.io/data/core/idnamespace/orgs/{ORG}/identities` endpoint has been deprecated. You may use the `/idnamespace/identities` endpoint to accomplish the same task and list all namespaces owned by a given organization.

**`Accept`:** `application/json`

### `GET /data/core/idnamespace/identities/{ID}` — Retrieve details of a specific identity namespace by its ID

The `https://platform.adobe.io/data/core/idnamespace/orgs/{ORG}/identities/{ID}` endpoint has been deprecated. You may use the `/idnamespace/identities/{ID}` endpoint to accomplish the same task and retrieve a specific namespace owned by a given organization.

**Path parameters:**
- `ID` **(required)** — The numeric value of the "id" field.

**`Accept`:** `application/json`

## Extra endpoints (present in the Postman collection, absent from the current OpenAPI specs)

These still work but were removed from, or moved in, the published specs. Treat them as legacy/alpha.
For computed attributes, the current spec exposes `GET /data/core/ca/attributes` instead.

### `GET /data/core/identity/mapping` — Given an identity and target namespace, returns the linked identity

Given an XID, returns all XID mappings in the requested namespace (`targetNs`). You must pass either `xid`, or the pair `namespace`/`nsid` + `id`.

**Query parameters:**
- `xid` — Identity string (XID) as returned by the identity endpoint.
- `nsid` — Namespace id. One of `namespace` or `nsid` is required with `id`.
- `namespace` — Namespace code. One of `namespace` or `nsid` is required with `id`.
- `id` — ID in the given namespace.
- `targetNs` — Target namespace id (or code) to map to. **(required)**

**`Accept`:** `application/vnd.adobe.identity+json;version=1.2`

### `GET /data/core/identity/cluster/history` — Cluster association statistics for an XID

Given an XID, returns all cluster associations with that XID. You must pass either `xid`, or the pair `namespace`/`nsid` + `id`.

**Query parameters:**
- `xid`, `nsid`, `namespace`, `id` — as above.
- `graph-type` — Graph type (for example `Private Graph` or `Device Graph`). **(required)**

**`Accept`:** `application/vnd.adobe.identity+json;version=1.2`

### `GET /data/core/idnamespace/orgs/{IMS_ORG}/identities` — List all namespaces for an org (legacy)

Lists all namespaces shared by `{IMS_ORG}`, or all owned namespaces if the path org matches the org in the header. Prefer `GET /data/core/idnamespace/identities`.

**Path parameters:**
- `IMS_ORG` **(required)** — The IMS Organization ID.

**`Accept`:** `application/json`

### `GET /data/core/idnamespace/orgs/{IMS_ORG}/identities/{ID}` — Retrieve a namespace for an org (legacy)

**Path parameters:**
- `IMS_ORG` **(required)**, `ID` **(required)** — Numeric namespace id.

**`Accept`:** `application/json`

### `GET /data/core/ups/config/computedAttributes` — List all computed attributes (alpha)

**Warning:** computed attributes are in alpha and not available to all users. Prefer `GET /data/core/ca/attributes`.

**Query parameters:** `limit`, `offset`, `sortBy`, `property` (same semantics as `/ca/attributes`).

**`Accept`:** `application/json`

### `GET /data/core/ups/config/computedAttributes/{ATTRIBUTE_ID}` — Retrieve a computed attribute (alpha)

**Path parameters:**
- `ATTRIBUTE_ID` **(required)**.

**`Accept`:** `application/json`
